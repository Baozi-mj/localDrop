# LocalDrop · 局域网文件快传

在电脑上跑一个单文件程序，手机扫码就能把电脑里的文件下载到手机上。不用装 App、不经过云盘、也不用先把文件复制上传一遍——同一个 Wi-Fi 下直连传输。

## 是什么

- 手机端零安装：扫二维码用浏览器打开就能接收，iOS / Android / 桌面浏览器都行。
- 文件不经过任何第三方服务器，只在你自己的电脑和局域网之间流动。
- 文件从磁盘原位置流式发送，不复制、不压缩、不占内存，支持 GB 级大文件。
- 每个文件独立下载，支持断点续传：切后台、锁屏、断网重连后都能接着下。文件多时可以点底部按钮一个一个自动下载。
- 电脑和手机两端都实时显示进度和速度。
- 拖拽文件到页面也能发送（浏览器不给磁盘路径，所以会先暂存一份副本，投送结束自动删除）。
- 只有一个可执行文件，前端资源已打包在里面。

## 快速开始

从 [Releases](../../releases) 下载对应平台的压缩包，解压后直接运行：

```bash
# macOS / Linux
./localdrop

# Windows：双击 localdrop.exe，或在命令行里运行
localdrop.exe
```

程序会自动打开浏览器里的管理界面，终端同时打印两个地址：

```
  LocalDrop v0.1.0 · 局域网文件快传
  ▸ 电脑管理界面   http://127.0.0.1:8787/#t=<admin-token>
  ▸ 手机访问地址   http://192.168.1.23:8787
```

也可以从源码构建（需要 Go 1.23+）：

```bash
go run .                    # 直接运行
go build -o localdrop .     # 编译成可执行文件
```

首次运行 macOS 可能提示「无法验证开发者」：在「系统设置 → 隐私与安全性」里点「仍要打开」，或执行 `xattr -d com.apple.quarantine ./localdrop`。

## 使用

1. 在电脑上打开管理界面，点「选择文件」或「选择文件夹」——macOS 会弹出系统选择窗口；Windows 和 Linux 使用内置的目录浏览器；也可以直接把文件拖进页面。
2. 点「开始共享」。页面会出现接收链接和二维码，以及当前有哪些手机连了上来。
3. 用手机扫二维码，点文件右侧的「下载」即可保存到手机，支持断点续传；文件多时点底部的「逐个下载」按钮，会一个一个自动下载。
4. 点「停止共享」结束投送，链接立即失效；已经下载完成的文件不受影响。投送 8 小时后也会自动结束。

保存到手机的位置由浏览器决定（iOS 一般在「文件」App 的「下载」里），本工具无法指定或修改。

## 命令行参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `-port` | `8787` | 监听端口，被占用时自动改用随机端口 |
| `-open` | `true` | 启动后自动打开管理界面，`-open=false` 可关闭 |
| `-awake` | `false` | 服务期间阻止系统休眠（仅 macOS） |

## 注意

- 服务是明文 HTTP，请只在可信的局域网里使用（家里、办公室 Wi-Fi）。同一个网络里知道链接的人就能下载文件，咖啡馆、酒店的公共网络别用。
- 管理界面只对本机开放；如果管理地址里的令牌泄漏给别人，对方就能控制你的投送，别把管理地址发出去。
- 同一时间只有一个进行中的投送，新建会替换旧的。
- 投送期间不要移动或删除要发送的源文件，否则对应下载会失败。
